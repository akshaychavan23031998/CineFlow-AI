How progress is calculated

Weighted DAG • not arbitrary AI percentage
Actual progress

Used when real telemetry exists: upload bytes, FFmpeg processed duration, confirmed task states.

Estimated progress (~)

Used when providers only expose queued/processing/completed. Historical timings provide an approximate value.

Weighted project progress

Σ(node weight × node progress) ÷ Σ(all node weights). Expensive/long stages contribute appropriately.

Input processing

What happens when users upload media
Image

Signed upload → GCS → Sharp normalize/thumbnail → quality/body/face checks → semantic analysis → Character/Asset metadata.

Video

Signed upload → GCS → FFprobe metadata → FFmpeg keyframes/audio extraction → multimodal analysis → usable reference metadata.

Audio

Signed upload → FFprobe metadata → speech/music classification → transcription/timestamps when needed → reusable audio asset.
